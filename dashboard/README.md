# ⚓ LH Nautical — Dashboard Executivo & Visual Analytics (Streamlit)

Aplicação web interativa de Visual Analytics e Inteligência Operacional desenvolvida para a **LH Nautical**.

---

## 📁 Estrutura do Diretório

| Arquivo | Descrição |
| :--- | :--- |
| **`app.py`** | Aplicação oficial desenvolvida em **Streamlit + Plotly**, com painéis analíticos interativos cobrindo performance de lojas físicas POS, segmentação VIP de clientes, modelagem preditiva de demanda, sistema de recomendação de produtos e auditoria transacional. |
| **`README.md`** | Instruções de configuração e inicialização do painel. |

---

## 🚀 Como Executar o Dashboard

```bash
# 1. Certifique-se de que o ambiente virtual está ativo
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate   # Windows

# 2. Inicie a aplicação Streamlit
streamlit run dashboard/app.py
```

O dashboard será aberto automaticamente no seu navegador no endereço:
👉 `http://localhost:8501`
